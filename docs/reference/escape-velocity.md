# Escape Velocity (1996) — founding reference

The game that started this. Every design decision traces back here.

## The basics

- Ambrosia Software, 1996, classic Mac OS (System 7), shareware
- 2D top-down space trading sim, open world, ~100 star systems, no forced
  objective

## The gameplay

- Start: basic shuttle, a few credits
- Three interlocking loops:
  - **Trading**: buy low, sell high — each world has its own commodities
    and prices
  - **Missions**: spaceport bars — delivery, pirate hunting, espionage; some
    unlock story arcs
  - **Combat**: real-time, juggling energy between weapons, shields, engines
- Factions: Confederation vs Rebellion — mission choices build reputation on
  one side and close doors on the other, with different endings
- Ship progression: shuttle → heavy freighter → capital ships; dozens of
  upgrades (weapons, shields, cargo, special systems)

## What made it special

- Genuine freedom: pirate, trader, mercenary, or faction hero — the game
  never pushes you anywhere
- Plug-in architecture: the community produced hundreds of extensions
- Sharp writing: planet descriptions and mission briefings had real tone

## Lineage

- Escape Velocity Override (1998): official sequel, new universe
- Escape Velocity Nova (2002): third installment, ported to Windows
- Endless Sky: open-source spiritual successor, same DNA, still maintained
