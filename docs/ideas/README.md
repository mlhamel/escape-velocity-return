# Idea inbox

One file per idea: `YYYY-MM-DD-slug.md`, starting with:

```
---
status: seeded
---
```

Status flow:

1. **seeded** — dumped here, unjudged
2. **groomed** — thought through, has acceptance criteria
3. **accepted** — scheduled into a milestone; promoted into `docs/gdd/`
4. **rejected** — kept with a one-line reason

Ideas are never deleted. This directory is the project's memory of what we
considered and why we said no.
