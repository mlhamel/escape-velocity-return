# Shared Economy (MMO)

[draft] — targets M3

All players trade in the same persistent market.

- Every sale/purchase moves local supply, which moves prices
- Server runs an economy tick (rate TBD) — not on every individual trade
- NPC freighters keep routes from being permanently broken
- Goal: a trader who watches the galaxy's news has an edge over one who
  memorized static routes
