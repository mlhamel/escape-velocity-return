# Prompt library

Curated prompts for kicking off work with agents. Naming: `NN-slug.md` per
category, e.g. `01-new-content-pack.md`.

Categories:

- **kickoff** — starting a milestone or feature area
- **content-gen** — generating ships/systems/missions consistent with the GDD
- **balance** — review passes on prices, ships, weapons
- **writing** — in-game text following docs/gdd/writing-style.md

A prompt file states: context to read first (which docs), the task, and
acceptance criteria. Prompts are versioned like everything else.
